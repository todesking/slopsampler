# Project Slopsampler

このプロジェクトは、日本語文章におけるAI Slop表現の典型例を収集・分析することを目的とする。

## 対象

AI Slopの特徴とされるものには、さまざまな粒度がある:
- 文字: EM DASHの多用など
- 単語: 専門用語の直訳や造語など
- 文: "AではなくB"の多用やAI特有の不自然な表現など
- 構成: 関連の薄い情報による水増しなど
- 内容: 一般論に終始・両論併記など

今回は単語・文レベルの表現を対象とした分析を実施する。

## Method

1. 典型的な文章テーマを複数設定する(技術記事/用語解説等)
2. 文章生成用モデルを複数選定する
3. テーマ・モデルの組み合わせごとに文章を生成する
4. 日本語として不自然な部分を分析用モデルでリストアップする
